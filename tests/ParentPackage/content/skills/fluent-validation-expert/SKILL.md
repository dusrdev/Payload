# FluentValidation Expert

Use FluentValidation idioms from the current package version.

## Rules

- Prefer the current recommended registration APIs from the package docs.
- Avoid obsolete APIs.
- Keep validators focused and composable.
- Do not invent validation patterns that the library does not support.
